# 启动程序并绑定窗口：Windows 手动验证

- [ ] 打开 `examples/launch-program-demo.json`，确认 `launch_program` 后成功启动记事本并激活唯一窗口。
- [ ] 将 `programPath` 改为带空格的程序路径，启动成功；加入带空格参数，程序收到的参数正确。
- [ ] 运行前出现启动任意程序的高风险确认；拒绝确认时程序不会启动。
- [ ] 将窗口 alias 留空配置（`"main": {}`），launch 后后续步骤使用已绑定窗口；没有 `launch_program` 的空白 alias 被校验拒绝。
- [ ] 对同一程序另开一个可见顶层窗口，launch 因新进程 PID 对应窗口不唯一而失败，不会任选窗口。
- [ ] 设置较短 `timeoutMs`，启动一个不创建可见窗口的程序，步骤超时并在该步报告失败。
- [ ] 设置要启动的程序为管理员权限更高的目标，普通权限的 WinAuto 拒绝绑定，不尝试自动化。
- [ ] 只运行 launch 后的步骤而跳过 launch，空白窗口 alias 在运行前明确报错，不会执行后续操作。
