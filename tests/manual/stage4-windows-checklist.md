# 阶段 4 Windows 手动验证清单（图形界面）

`ui/` 下的 Qt 代码**从未被编译过**（容器里装不了 Qt），只做过人工审查。编辑规则、调试闸门、引擎的步骤范围已有单元测试；
这份清单验证界面本身。**用空白记事本验证，不要在有未保存内容的窗口上运行。**

## 0. 编译
- [ ] 重新构建（CMake 需找到 Qt 5.15 的 `Qt5Widgets`），`winauto-ui` 能链接。
- [ ] `ctest -C Debug` 应为 15 个测试项全部通过。
- [ ] 编译报错请把完整错误贴给我（Qt 相关的拼写/签名问题最可能出现在 `MainWindow.cpp`、`StepPanel.cpp`、`ElementPickerDialog.cpp`）。
- [ ] 若启动时提示缺少 Qt DLL，用 `windeployqt winauto-ui.exe` 或把 Qt 的 bin 加入 PATH。

## 1. 编辑（不会操作任何窗口）
- [ ] 启动后"文件 → 打开"`examples\notepad-demo.json`：步骤列表出现；点各步，右侧面板内容与 JSON 一致，不相关的字段被隐藏（如 wait 只有时长）。
- [ ] "流程 → 目标窗口…"：别名/进程名/标题可编辑；"从窗口列表添加…"能列出窗口，管理员窗口是红色且不能选。
- [ ] 改别名：引用它的步骤同步改名；删除仍被引用的别名 → 提示并拒绝。
- [ ] 添加/复制/删除/上移/下移步骤；编号不重复；Ctrl+Z / Ctrl+Y 能撤销重做；标题栏的 `*` 随修改出现，保存后消失。
- [ ] 把某步 id 改成已有的 id → 弹出"无法修改"，面板恢复原值。
- [ ] 故意制造错误（click 步骤清空定位器）：该行变红、悬停有原因、面板底部列出问题、状态栏错误数增加。
- [ ] 定位器框里输入错误 JSON：面板显示红色错误，**不提交**；改对后自动提交。
- [ ] 保存后用 `cli validate` 校验同一文件，应通过；再用界面重新打开，内容不变。
- [ ] 在定位器框里连续输入文字时，光标不应跳走（提交后不重载面板）。

## 2. 拾取控件
- [ ] 打开一个记事本；给步骤选好目标窗口；点"拾取控件…" → 出现控件树；过滤框能按名称/类型过滤。
- [ ] 选中文本区 → 下方出现建议的 locator；"使用此定位器"后写进步骤的定位器框。
- [ ] "鼠标拾取"：点击后把鼠标移到记事本文本区上，3 秒后该控件被选中（对话框可能遮挡，把它拖开）。
- [ ] 目标程序没打开 → 提示找不到窗口，不崩溃。
- [ ] 没有 automationId 的控件 → 建议里有"名称易变"警告。

## 3. 运行与安全（先验证紧急停止）
- [ ] 点"运行全部"→ 弹出信任摘要，内容与流程一致；**默认按钮是"取消"**，回车不会启动；敏感文本不显示。
- [ ] 流程里有 Alt+F4 / Delete 这类步骤 → 还会要求输入 `RISK`。
- [ ] 运行时按 **Ctrl+Alt+F10** → 立即停止，日志显示已取消。
- [ ] 先开 `cli stop-hotkey-test` 占用热键，再在界面运行 → 拒绝运行并说明原因。
- [ ] 运行期间界面不卡死，步骤行依次显示 ▶ → ✔；失败的步骤显示 ✖ 且日志有原因。
- [ ] `textFrom: prompt` 的步骤弹出密码框；取消 → 流程以 Cancelled 结束。
- [ ] 运行中不能编辑（面板灰掉）、不能关闭窗口（提示先停止）。

## 4. 调试
- [ ] F11 从头单步：停在第一步之前，该行高亮；F10 执行一步后停在下一步；日志有提示。
- [ ] F9 跳过当前步：该步显示 ↷，目标程序里没有发生对应操作。
- [ ] F8 继续：后面的步骤连续执行。运行中 F6 暂停 → 下一步之前停住。
- [ ] 选中某一步按 Ctrl+F5：**只**执行这一步；目标窗口之外的别名即使不存在也不影响。
- [ ] 调试停住时按 Ctrl+Alt+F10 或 Shift+F5 → 立即结束。

## 5. 高分屏
- [ ] 在 125% / 150% 缩放的显示器上，拾取控件和坐标点击的位置仍然准确（工具关闭了 Qt 自动缩放，使用物理像素）。
- [ ] 界面文字大小是否可读（如果太小，告诉我，我会按 DPI 调整字体而不是重新打开 Qt 缩放）。
