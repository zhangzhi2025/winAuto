## 1. 剪贴板输入
- [ ] 先在别处复制一段文字 A。新建流程：激活记事本 → 输入文本（方式选"剪贴板粘贴"，内容含多行和中文/emoji）→ 运行。记事本里是完整文本，**换行与字符不丢**。
- [ ] 运行结束后在记事本里按 Ctrl+V → 粘出来的是 **A**（剪贴板已还原）。
- [ ] 运行前复制一张图片（截图）再重复：结束后 Ctrl+V 能粘出那张图（非文本格式也被还原）。
- [ ] Win+V 打开剪贴板历史：**不应出现**本流程写入的文本。
- [ ] 勾选"敏感内容"或"运行时询问"后改用剪贴板 → 属性面板/校验报错 `sensitive_clipboard`。
- [ ] 运行中途按 Ctrl+Alt+F10 停止（在输入前后各试）：剪贴板仍被还原。
- [ ] 目标窗口不在前台时 → `InputBlocked`，且剪贴板未被改动。

## 2. 失败自动截图
- [ ] 流程属性里勾选"失败时自动截取目标窗口画面"，保存流程。让某一步必然失败（如点击不存在的控件）并运行。
- [ ] 日志里出现 `screenshot saved: ...`；流程文件旁出现 `screenshots\<时间戳>\fail-001-<步骤id>.png`，图片是目标窗口当时的画面（含盖在上面的弹窗）。
- [ ] 菜单"运行 → 打开失败截图文件夹"能打开该目录。
- [ ] `onFailure: continue` 且多个步骤失败 → 每个失败各一张；序号递增。
- [ ] 流程里有"运行时询问/敏感"的输入步骤：该步骤**之后**失败不再截图（校验会给出一条提示警告）。
- [ ] 目标窗口被最小化/关闭后失败 → 不截图、不崩溃，日志有说明或直接略过。
- [ ] CLI：`winauto-cli run flow.json --screenshot-dir D:\shots` 同样生效。

## 3. 条件与循环（界面）
- [ ] 编辑 → 添加步骤，能加"如果 / 重复 / 当…时循环"。选中块后"添加到所选块内"把步骤放进去，列表里按层级缩进显示；"否则"分支里的步骤带"否则 ▸"。
- [ ] Alt+→ / Alt+← 缩进/取消缩进；上移下移只在同一层内移动；删除块时提示会一起删除子步骤，撤销可恢复。
- [ ] if：条件选"控件存在时成立"，用"拾取控件"填入记事本编辑区，运行 → 走 then；改成不存在的控件 → 走 else（日志里有 `condition is true/false`）。
- [ ] 条件定位器**有歧义**（匹配多个控件）→ 步骤失败 `ElementAmbiguous`，**不会**悄悄走 else。
- [ ] repeat 3 次：每轮内的步骤都执行；运行日志里同一步骤出现 3 次。
- [ ] while：条件始终成立、maxIterations=5 → 第 5 轮后失败 `LimitExceeded`；条件在第 3 轮后消失 → 正常结束。
- [ ] "流程属性 → 步骤执行次数上限"设成很小（如 5）并运行 repeat 100 → `LimitExceeded`，立即停止。
- [ ] 单步调试：每个子步骤、每一轮都会停；F9 跳过块 = 整块跳过；选中嵌套里的一个步骤"只运行选中步骤" → 只跑这一步，忽略外层条件。
- [ ] 运行前确认框里的摘要按缩进列出 if/repeat/while 及其内容，并写明循环上限。
- [ ] 打开 `examples\flow-control-demo.json`（记事本）能正常显示并运行。

## 4. 截取模板按钮
- [ ] 选中一个 click 步骤 → 属性面板"截取模板…"。流程没保存时先提示保存。

- [ ] 拖拽框选一块（如记事本菜单栏的"文件"）。下方给出评估：纯色/太小 → 不能确定；在窗口里出现多处 → 提示并建议"限定搜索范围"；唯一 → 绿色通过。
- [ ] 确认后：流程旁出现 `templates\<步骤id>-N.png`；定位器框自动填入 `strategy: image`，勾选限定范围时带 `searchRegion`。

- [ ] if / while 的"条件定位器"和 expect 旁的"截取模板…"同样可用。
- [ ] 目标窗口找不到 / 管理员窗口 → 弹出明确的错误，不崩溃。
- [ ] 多显示器、125%/150% 缩放下：截图里的像素与实际一致（选区不偏移）。
